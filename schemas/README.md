# Exported JSON Schemas

Generated by `chd-atlas schemas export`. Do not edit by hand — a test fails if these drift from
the Pydantic models in `src/chd_atlas/models/`.

## What these check

Identifier patterns, enum membership, required fields, minimum list lengths, rejection of unknown
keys, and the evidence locator's discriminated union.

## What these do NOT check

Every cross-field rule. A record can satisfy these schemas and still be rejected by
`chd-atlas validate` — for example omics evidence with no dataset accession, a syndromic assertion
listing no extracardiac features, a GEO accession filed under PRIDE, mass-spectrometry technology in
a sequencing archive, a review date preceding its curation date, or morpholino perturbation in a
mammal.

Note also that JSON Schema's `format: date` is annotation-only in most validators, so `2026-13-45`
will pass here and fail in `chd-atlas validate`.

Passing these schemas means a record is **well-formed**, not that it is **valid**.
